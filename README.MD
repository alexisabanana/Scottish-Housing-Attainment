# Scottish Housing & School Attainment

## Overview

This project explores the relationship between educational attainment and median house prices across Scottish Data Zones between 2014 and 2018.

Built using Tableau Public, the dashboard combines Scottish housing and school-leaver attainment data to investigate whether areas with higher attainment scores also tend to have higher median house prices.

## Business Question

**Is there an observable relationship between area-level educational attainment and median house prices in Scotland?**

The analysis explores this question at Data Zone level. It does not attempt to establish a causal relationship.

## Methodology

The datasets were aligned using 2011 Data Zone geography codes and comparison years. The analysis focuses on the overlapping period from 2014 to 2018.

House-price records were restricted to median prices. Attainment reporting periods use three-year rolling windows, which means adjacent annual observations are not independent.

Records without a matching attainment value require separate treatment when comparing both measures. The dashboard should be interpreted alongside the limitations of the underlying data.

## Key Considerations

- Area-level patterns do not necessarily reflect individual household circumstances.
- Correlation does not establish causation.
- Three-year rolling attainment periods overlap.
- Extreme values and unmatched records can influence results.
- The findings describe an association between area-level measures, not the effect of house prices on educational outcomes.
